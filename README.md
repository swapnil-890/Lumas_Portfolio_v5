# Swapnil Roy — Portfolio

Personal portfolio site for Swapnil Roy, AI & Systems Engineer.

## Stack
Next.js 14 (App Router) · TypeScript · Tailwind CSS · MDX · GitHub API

## Contents
- `/` — Identity, current focus, engineering work index, skills matrix
- `/work/vovera` — Voice attack detection pipeline (FastAPI, SQLite)
- `/work/core7` — RAG with guardrail middleware (ChromaDB, sentence-transformers)
- `/work/steel-raven` — Biomimetic drone concept (CFRP, Fusion 360)
- `/off-duty` — Personal interests

## Development
```bash
npm install
npm run dev
```

## Environment
Copy `.env.example` to `.env.local` and set:
- `GITHUB_TOKEN`
- `GITHUB_USERNAME`
- `NEXT_PUBLIC_SITE_URL`
